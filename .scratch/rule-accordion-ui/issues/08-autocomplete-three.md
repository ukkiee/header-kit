# 08 — 자동완성 3종 (헤더 이름 · 쿠키 이름 · User-Agent)

**What to build:** 헤더 이름을 칠 때 표준 헤더와 전에 쓴 이름이 제안된다(이미 있는 동작을 유지). 쿠키 이름을 칠 때 흔한 쿠키 이름과 전에 쓴 이름이 제안된다. User-Agent 값을 정할 때 미리 준비된 UA 문자열을 **라벨로 골라** 넣는다 — 긴 문자열을 외우거나 어디선가 복사해 오지 않아도 된다.

세 필드가 같은 구조를 쓴다: 프리셋 사전 + 사용 이력. 직접 친 값은 다음에도 제안된다. UA만 예외적으로 접두 필터가 맞지 않아(문자열이 길다) 라벨로 검색하고 값을 넣는 형태다.

시안에 없지만 제품 소유자가 명시적으로 지시한 항목이다(ADR 0017의 유일한 예외).

**Blocked by:** 06 (규칙 폼 — 세 필드가 그 안에 있다)

**Status:** ready-for-agent

- [ ] 헤더 이름 제안이 그대로 동작한다
- [ ] 쿠키 이름 제안이 프리셋 + 사용 이력으로 뜬다
- [ ] User-Agent를 라벨로 찾아 고르면 전체 문자열이 값에 들어간다
- [ ] 직접 친 쿠키 이름과 User-Agent가 다음에도 제안된다
- [ ] 이력 배열이 검증 **전에** 기본값을 받아, 없던 상태를 읽어도 전체가 기본값으로 교체되지 않는다
- [ ] 제안 로직이 순수 함수로 단위 테스트된다
