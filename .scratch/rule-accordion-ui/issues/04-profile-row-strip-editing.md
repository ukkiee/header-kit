# 04 — 프로필: 편집 컨트롤 제거, 행 시안 정합

**What to build:** 프로필 목록에서 할 수 있는 일이 **만들기·켜고 끄기·순서 바꾸기·검색** 넷으로 줄어든다. 이름 변경·색 변경·복제·삭제가 사라지고, 호출부 없는 명령들도 함께 퇴역한다. 두 글자 라벨은 어디에서도 렌더되지 않던 죽은 필드라 같이 뺀다.

행은 시안대로 `색 스와치 + 이름 + N개 규칙 · 적용 + 토글 스위치`가 된다. 스와치는 읽기 전용이고, `＋ 새 프로필`은 이름과 색을 자동으로 정해 바로 선택한다.

**되돌리는 유일한 길이 전체 초기화가 된다는 뜻이다** — 시안이 그린 대로 가는 결정이고 ADR 0017에 근거가 있다.
