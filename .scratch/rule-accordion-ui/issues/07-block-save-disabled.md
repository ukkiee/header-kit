# 07 — Block 저장 버튼 비활성화

**What to build:** Block 규칙의 URL 패턴이 브라우저가 못 쓰는 것이면 **저장 버튼이 비활성화되고 그 사유가 함께 보인다**. 못 쓰는 패턴으로 저장이 되면 목록에는 정상으로 보이고 토글도 켜져 있는데 실제로는 아무것도 차단되지 않는다 — 차단이 걸렸다고 믿는 채로 광고·추적이 그대로 지나간다.

넓다는 이유로 한 번 더 묻던 단계는 사라진다. 넓은 것은 사용자가 정말 원했을 수 있는 정당한 상태다.

비활성 버튼이 이유 없이 죽어 있으면 왜 안 눌리는지 몰라 헤매게 되므로, 사유는 반드시 함께 보인다.

**Blocked by:** 06 (규칙 폼)

**Status:** ready-for-agent

- [ ] 못 쓰는 패턴이면 저장 버튼이 비활성화된다
- [ ] 비활성화된 이유가 폼 안에서 함께 보인다
- [ ] 넓은 스코프의 Block 규칙은 되묻지 않고 그냥 저장된다
- [ ] 다른 종류의 규칙은 이 검증에 걸리지 않는다
- [ ] 스코프 판정 자체는 와일드카드·정규식 두 가지만 노출된 뒤에도 그대로다
