# 09 — 백업·설정 화면 시안 정합

**What to build:** 백업 화면이 카드 넷이 된다 — JSON 내보내기·가져오기 / 클라우드 동기화 스위치와 지금 어디에 저장되는지 알려주는 문구 / 백업 히스토리(시각·요약·복원·삭제) / 전체 초기화(두 번 눌러야 실행). 설정 화면은 테마 칩 셋 + 배지 표시 토글 + 언어(한국어·영어)만 남는다.

단축키 패널·디버그 토글·일본어는 시안에 있지만 넣지 않는다(ADR 0017의 경계). 동기화 상태 문구에서 **기기 수는 쓰지 않는다** — 알 수 없는 값이다. 저장 위치와 마지막 시각만 말한다.

**Blocked by:** 03 (셸 — 이 화면들은 프로필 열이 사라진 넓은 본문에 그려진다)

**Status:** ready-for-agent

- [ ] 백업 화면이 시안의 카드 넷 구성이다
- [ ] JSON 내보내기·가져오기가 한 카드에 있다
- [ ] 동기화 스위치와 지금 어디에 저장되는지 알려주는 문구가 있고, **기기 수는 말하지 않는다**
- [ ] 백업 히스토리에서 시각·요약을 보고 복원·삭제한다
- [ ] 전체 초기화가 두 번 눌러야 실행된다
- [ ] 설정이 테마 칩(다크·라이트·시스템) + 배지 토글 + 언어(ko/en)다
- [ ] 단축키 패널·디버그 토글·일본어가 없다
- [ ] 두 화면이 프로필 열 없는 넓은 본문에서 정상으로 그려진다
