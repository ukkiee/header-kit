# 05 — 아코디언 규칙 카드 + 행 칩 줄

**What to build:** 규칙 행의 수정 아이콘을 누르면 **그 행이 그대로 남은 채** 아래로 폼이 펼쳐지고, 그 규칙이 목록 맨 위로 올라온다. 저장하거나 취소하면 접히고 원래 순서로 돌아온다. 지금은 행이 사라지고 자리에 폼이 들어서서, 무엇을 고치는 중인지 화면에서 없어진다 — 그것을 고치는 것이 이 티켓이다.

행이 시안 구성이 된다: 토글 스위치 + (메모 또는 종류 이름) + 종류 뱃지, 둘째 줄에 URL 스코프 칩이 먼저 오고 그 뒤로 효과·리소스 묶음·요청 메서드 칩이 이어진다. 응답 쿠키면 속성 칩이 그 사이에 들어간다.

리소스 묶음 모듈이 여기서 선다 — 여덟 개 사용자 묶음과 브라우저의 열다섯 가지 값 사이를 양방향으로 옮기고, `문서`는 최상위 문서와 프레임 안 문서를, `기타`는 나머지 일곱 가지를 함께 뜻한다. **여덟 개로 열다섯 가지에 빠짐없이 도달한다.**

새 규칙 폼은 목록 **맨 위**에 카드로 열린다.

**Blocked by:** 01 (응답 쿠키 속성 칩이 구조화된 필드를 읽는다), 03 (셸 — 카드가 그 본문 안에 그려진다)
