# 03 — 셸: 레일 · 프로필 열 조건부 표시 · 본문 헤더 바

**What to build:** 왼쪽 레일에서 프로필·백업·설정을 오가고, 레일 아래에서 지금 실제로 걸려 있는 규칙 수를 본다. **프로필 열은 프로필 화면에서만 선다** — 백업·설정으로 가면 사라져 본문이 넓어진다. 본문 헤더가 지금 보는 프로필의 이름을 제목으로, `N개 적용 규칙 · N개 활성 프로필`을 부제로 보여 주고, 오른쪽에 일시정지 버튼과 `＋ 규칙 추가`가 선다.

프로필 열을 숨기는 것은 ADR 0005 개정이다. 그 결정이 막으려던 문제("백업을 보는 중에 프로필을 눌러도 아무 일이 안 일어난 것처럼 보인다")는 누를 것이 없어져 함께 사라지므로, 그때 넣은 "고르면 프로필 화면으로 함께 이동" 보정도 뺀다.

팝업의 '탭에서 열기' 버튼은 남는다 — 시안의 기준 크기가 팝업 하드리밋 밖이라 탭 앱이 그 문이다.

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] 프로필 열이 프로필 화면에서만 서고, 백업·설정에서는 본문이 그 폭을 가져간다
- [ ] "고르면 프로필 화면으로 함께 이동" 보정이 사라진다
