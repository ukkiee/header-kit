# 08 — 전체 초기화 (멱등)

**What to build:** 2단계 확인을 거친 공장 초기화. 프로필·설정·백업·설치된 규칙을 모두 지워 깨끗한 default 상태로 되돌린다. 되돌릴 수 없는 파괴적 동작임을 인정하고, 저널·롤백 대신 각 단계를 멱등·재시도 가능하게 만들어 중간에 실패해도 다시 눌러 끝까지 밀 수 있게 한다.

**Blocked by:** 01 (백업 화면 셸), 07 (sync/local 저장소 처리 재사용).

**Status:** ready-for-agent

- [ ] 2단계 확인(한 번 더 눌러 확인) 후에만 실행된다
- [ ] 지우는 대상: 모든 프로필(→ 단일 default 하나), 선호값(테마·배지·언어·sync 플래그 → 기본값), 로컬 스냅샷, sync 스냅샷, 세션 요약, 설치된 dNR 규칙(재컴파일로 비워짐)
- [ ] 자동 백업을 먼저 중단 → 저장소(local+sync 백업 키) 비움 → 상태를 default로 리셋 → 자동 백업 재개(깨끗한 default 스냅샷은 의도된 동작). 방금 지운 데이터가 되살아나지 않는다
- [ ] 각 삭제 단계는 이미 비어 있어도 안전하게 다시 실행된다(멱등). 한 단계 실패 시 오류를 표면화하되 완료된 삭제를 **되돌리지 않으며**, 다시 눌러 남은 단계를 마칠 수 있다(롤백 아님)
- [ ] core 테스트: 채워진 local+sync에서 열거된 키·상태를 비움, 자동 백업 중단→재개로 재생성 없음, 한 단계 실패 후 재실행(멱등)이 끝까지 완료 (prior art: backup.test.ts·commands.test.ts)
- [ ] smoke: 2단계 확인 후에만 초기화가 실행된다
