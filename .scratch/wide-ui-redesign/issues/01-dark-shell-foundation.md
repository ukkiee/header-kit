# 01 — 다크 셸 파운데이션 (걷는 해골)

**What to build:** 디자인의 다크 개발자도구 톤을 두 표면(팝업·탭 앱)이 공유하는 셸에 입힌다. 사용자는 어느 표면에서든 어두운 셸 — 왼쪽 레일(아이콘+라벨: 프로필/백업/설정), 프로필 열(검색·색 스와치·인라인 토글·"새 프로필"), 아코디언 규칙 카드 — 을 보고, 규칙 행의 수정 아이콘을 누르면 그 규칙이 맨 위로 올라오며 RuleForm이 인라인으로 펼쳐지고 저장하면 접혀 두 줄 요약으로 돌아온다. 새 규칙 종류·테마 스위치는 이 티켓에 없다 — 다크가 고정된 룩이다. 이 셸이 나머지 모든 티켓이 렌더되는 토대이므로 **구조 게이트가 이 티켓 직후** 붙는다.

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] 두 표면이 디자인 다크 팔레트로 렌더된다 (팝업 760×580 고정, 탭 전폭·전고 — ADR 0005)
- [ ] Geist·Geist Mono가 로컬 번들(자가 호스팅 woff2)로 적용되고 원격 폰트 요청이 0이다
- [ ] 레일이 아이콘+텍스트 라벨로 프로필/백업/설정을 오가고, 하단에 적용 규칙 총수를 보인다
- [ ] 프로필 열이 검색·색 스와치·인라인 토글·"새 프로필"을 갖는다
- [ ] 규칙이 아코디언 카드로 렌더되고, 수정 아이콘 → 해당 규칙 맨 위 정렬 + RuleForm 인라인 펼침, 저장 시 접힘 (ADR 0006/0009와 정합)
- [ ] 상태가 색만이 아니라 위치·형태로도 구분된다(색각 이상 대비), 포커스가 보인다
- [ ] 기존 shadcn+Base UI+Tailwind+Motion 스택으로 구현, 새 라이브러리 없음 (ADR 0015)
- [ ] ui-diag: 탭 와이드 가로 오버플로 0, 팝업 760×580 유지, 시작 지표 무회귀, 다크 스크린샷
- [ ] 전 게이트 그린: tsc · vitest · smoke · storybook · bundle-gate · ui-diag
