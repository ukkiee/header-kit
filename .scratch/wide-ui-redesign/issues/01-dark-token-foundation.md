# 01 — Geist + 다크 토큰 파운데이션 (걷는 해골)

**What to build:** 디자인의 다크 톤과 서체를 **토큰 계층 하나**로 확립한다 — 구조·레이아웃은 아직 건드리지 않는다. Geist·Geist Mono를 로컬 번들로 깔고, 다크 모드의 시맨틱 토큰 값을 디자인의 near-black 팔레트(#0a0a0a 계열)와 accent(#1d4ed8)로 재매핑하며, 셸이 아직 raw zinc 유틸(`bg-zinc-100` 등)로 칠하던 곳을 시맨틱 토큰(`bg-secondary` 등)으로 바꿔 **토큰 값 하나로 전체가 리테마**되게 한다. 라이트 모드는 손대지 않는다(같은 시맨틱 토큰의 라이트 값 그대로).

이게 나머지 모든 티켓이 렌더되는 **색·서체 토대**이고, 여기서 확립하는 "모든 것은 시맨틱 토큰에서 테마된다"는 패턴을 **구조 게이트가 검토**한다. 레일 라벨·프로필 열·아코디언 같은 구조 재작업은 티켓 10이 이 위에 올린다.

**Blocked by:** None — can start immediately.

**Status:** done

- [ ] Geist·Geist Mono가 로컬 번들(@fontsource-variable/geist, woff2)로 적용되고 원격 폰트 요청이 0이다. `--font-sans`/`--font-mono`가 Geist를 가리킨다
- [ ] 다크 모드 시맨틱 토큰 값이 디자인 near-black 팔레트로 재매핑된다(배경/카드/보더/입력 표면 + accent #1d4ed8). 라이트 값은 불변
- [ ] 셸(app.tsx)과 프리미티브 토큰(tokens.ts)·피처 컴포넌트가 다크 룩을 나르던 raw zinc 유틸을 **시맨틱 토큰으로 전환** — 토큰 값 변경만으로 리테마된다
- [ ] **구조·레이아웃은 이 티켓에서 바꾸지 않는다** — 레일은 아이콘 그대로, 그리드 치수·프로필 열·규칙 행 구조 불변 (그건 티켓 10)
- [ ] 다크 대비 기준 유지(본문 4.5:1, 비텍스트 3:1)
- [ ] 색을 못박던 스모크 단언(예: N22a 스크롤바 색)을 새 토큰 값으로 갱신 — 계약을 무르게 하지 않고 값만
- [ ] 전 게이트 그린: tsc · vitest · smoke · storybook · bundle-gate · ui-diag(다크 스크린샷이 새 팔레트를 보임)
