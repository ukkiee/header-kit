## 측정치 (이 파일이 정본 — 다른 문서·주석은 여기를 가리킨다)

계량은 전부 popup **즉시 로드 집합 합계**(min·비압축) 기준이다.

| 단계 | 즉시 합계 | baseline 대비 | 비고 |
|---|---|---|---|
| 마이그레이션 전 | 519.1KB | +133.1KB | 한도 143KB, 여유 9.9KB |
| Base UI 1.0.0-rc.0 → 1.6.0 | 527.0KB | +141.0KB | **+7.9KB**, 여유 2.0KB |
| + `cn`(clsx + tailwind-merge) | 553.6KB | +167.6KB | **+26.6KB** — 한도 24.6KB 초과 |
| 미사용 shadcn 11개 삭제 후 | 552.1KB | +166.1KB | 1차 한도 175KB |
| 조합 파일 6개 완성 후(최종) | 566.5KB | +180.5KB | **+14.4KB**, 최종 한도 190KB, 여유 9.5KB |

**tailwind-merge 하나가 +26.6KB다** — 추정(6~7KB)의 4배. v4 클래스 그룹 테이블을 통째로 담기 때문이고, 이 값이 이번 재트리아지의 유일한 원인이다.

CSS는 게이트 밖이라 따로 적는다: **37.8 → 96.7 → 71.6KB**. 가운데 값이 `tw-animate-css` + shadcn 유틸이 들어온 직후, 마지막이 미사용 컴포넌트 11개를 지운 뒤다. **쓰지 않는 컴포넌트가 CSS를 25KB 불렸다** — Tailwind는 소스를 스캔하므로 import하지 않아도 그 파일의 클래스가 CSS에 실린다. 최종 증가분 +33.9KB는 알고 받아들인 비용이다.

**시작 지표** (기준선 first paint 64.0ms · dom ready 36.7ms): 승격 후 80.0ms, tailwind-merge 도입 후 76.0ms, 최종 76.0ms. **회귀 없음** — 세 값의 차이가 ui-polish 01이 기록한 실행 간 변동 폭(first paint ±8ms) 안에 있다. 단일 실행의 숫자를 개선/악화의 근거로 쓰지 않는다.

마지막 +14.4KB는 조합 파일(`press-button`·`toaster`·`text-field`·`select-options` 등)이 shadcn 컴포넌트를 **실제 import 체인에 들이면서** 생겼다. 인프라만 깔았을 때는 shadcn 소스가 저장소에 있어도 아무도 부르지 않아 트리셰이킹으로 빠져 있었다. 그래서 한도를 175로 잡았다가 190으로 한 번 더 올렸다 — 아래 재트리아지의 근거는 두 번 모두 같다.

`badge.tsx`도 이 시점에 지웠다(유일한 grep 매치가 브라우저 액션 배지인 `core/badge.test.ts`였다). JS는 줄지 않았다 — 아무도 부르지 않아 이미 트리셰이킹돼 있었다. 지운 이유는 크기가 아니라 재복사 대상을 늘리지 않기 위해서다.

## 번들 한도 재트리아지 (+143KB → +175KB → +190KB)

스펙의 에스컬레이션 사다리를 순서대로 밟았다.

1. **지연 로드** — 불가. `cn`은 거의 모든 프리미티브가 첫 페인트에 부른다. 지연시킬 경계가 없다.
2. **대안** — clsx만으로 `cn`을 구현하는 안을 실제로 제시했다. 26.6KB를 아끼고 게이트를 그대로 지키지만, className 충돌이 CSS 소스 순서로 결정되어 shadcn 소스를 **수정 없이** 받는다는 이 마이그레이션의 전제가 흔들린다. 사용자가 기각했다.
3. **사용자 재트리아지** — 승인받아 175KB로 조정.

**이번 변경은 완화가 맞다.** 143KB까지의 세 번은 계량 범위를 넓히면서 여유를 그대로 둔 재표현이었지만(게이트가 오히려 촘촘해졌다), 이번은 남는 여유를 늘렸다.

근거는 추정이 아니라 실측이다. 번들 게이트는 체감 속도의 **대리** 지표이고 직접 지표(ui-diag의 시작 계측)가 따로 있는데, 둘이 엇갈렸으므로 직접 지표를 채택했다 — ui-polish 02가 135KB로 올릴 때와 같은 논리다. 확장은 로컬 로드라 네트워크 다운로드가 없다는 ui-refine 08의 근거도 그대로 유효하다.

## Further Notes

- `shadcn add`는 **WXT 환경에서 저장소 밖에 쓴다.** `.wxt/tsconfig.json`의 `paths`(`@/*` → `../src/*`)를 프로젝트 루트 기준으로 해석해 `<repo>/../src/ui/`에 파일을 만든다. 이번에도 21개가 `~/workspace/src/ui/`에 생성됐고 옮긴 뒤 잔여 디렉터리를 지웠다. 추가할 때마다 생성 위치를 확인한다.
- 미사용 shadcn 컴포넌트는 지운다. 저장소에 두면 재복사 대상만 늘고 CSS도 25KB 불린다. 필요해지면 `shadcn add`로 다시 받는다.
