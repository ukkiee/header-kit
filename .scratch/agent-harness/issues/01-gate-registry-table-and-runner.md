# 01 — 게이트 표에 소유자가 생긴다: 레지스트리·표·러너

**What to build:** `bun run gate` 한 번으로 이 저장소의 게이트가 돌고, 행마다 PASS / FAIL / N/A 판정이 **게이트가 실제로 출력한 것**에서 나온다. 지금은 무엇이 게이트인지 한자리에서 말하는 문서가 없어 판정을 매번 그때의 검증 문서가 새로 만든다 — 그 상태가 끝난다.

사람이 읽는 표는 `docs/agents/verification.md`가, 기계가 읽는 레지스트리는 `scripts/gates.txt`가 갖는다. 레지스트리가 **"무엇이 게이트인가"의 정의**이고, 러너는 돌리는 일에 더해 레지스트리·표·`package.json`·CI 워크플로 **네 자리가 서로 어긋나지 않았는지**를 검사한다.

이 티켓은 **빌드 산출물을 읽지 않는 게이트만** 등록한다: `check`·`test`·`build`·`storybook:build`, 그리고 지금 등록되지 않아 사실상 아무도 돌리지 않는 `audit-smoke-barriers`. 산출물을 읽는 게이트는 회차별 디렉터리가 서는 02 뒤에 들어온다 — 지금 등록하면 낡은 산출물을 재는 상태가 그대로 표에 들어온다.

`audit-smoke-barriers`의 헤더는 자신이 등록되지 않는 것이 **의도**라고 적고 있다. 그 결정을 개정한다: 헤더가 든 근거(인자로 다른 리비전을 검사할 수 있다)는 등록과 공존하므로 등록을 막지 못하고, 미등록의 비용은 실재한다 — 이 감사는 smoke의 단언이 한 테스트씩 밀리는 결함을 막는 것인데 사람이 기억해야 돌아가면 기억하지 않은 날 무방비해진다. 헤더의 해당 문단을 고치고 개정 이유를 판정 대장에 남긴다.

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] `bun run gate`가 등록된 게이트를 전부 돌리고 행별 판정을 낸다. 판정의 근거는 게이트가 출력한 실제 내용이지 러너가 지어낸 문장이 아니다
- [ ] 레지스트리의 한 행이 `id`·`script`·`kind`(hard/advisory)·`ci`·`needs`·`browser`·`na` 필드를 든다. `na`는 그 행이 `N/A`가 될 수 있는 **유일한 조건**이며 없으면 `never`
- [ ] 네 자리 일치가 **등록된 게이트에 대해서만** 성립한다 — 레지스트리 행에 대응하는 표의 행이 없거나, `package.json`에 그 스크립트 키가 없거나, `ci: yes`인데 워크플로에 없거나, 워크플로가 등록되지 않은 게이트를 돌리면 FAIL
- [ ] **평범한 non-gate 스크립트가 있어도 통과한다.** `dev`·`zip`·`test:watch`·`storybook`·`postinstall`이 검사에 참여하지 않는 것을 픽스처로 확인한다 — 참여시키면 그 규칙은 영구히 빨강이라 검사가 아니라 소음이다
- [ ] `scripts/`에 `*-gate.mjs`가 있는데 레지스트리에 없으면 FAIL. 그리고 **그 이름 규약 밖의 고아 게이트는 잡히지 않는다는 경계**가 표에 적혀 있고, 그 사실을 확인하는 케이스가 테스트에 있다 — 덮지 못하는 것을 덮은 척하지 않는다
- [ ] CI 워크플로가 아직 없는 상태가 정상 통과다(모든 행이 `ci: no`). 워크플로가 없는데 `ci: yes`인 행이 있으면 FAIL
- [ ] 게이트가 실패했을 때 러너가 그 게이트의 출력을 **버리지 않고 보고한다**. 출력을 버리면 빨강이 났을 때 무엇이 실패했는지 영영 알 수 없다
- [ ] `audit-smoke-barriers`가 `bun run smoke-barriers`로 등록되고, `-- <경로>`로 다른 리비전을 검사하는 능력이 그대로 남아 있다. 헤더의 '등록하지 않는다' 문단이 개정됐다
- [ ] 테스트가 러너를 **자식 프로세스로 띄우고 종료 코드와 상태 줄만** 단언한다. 러너의 내부 함수를 부르지 않는다
- [ ] `vitest.config.ts`의 include가 `scripts/**/*.test.mjs`를 덮되 `*.browser.test.mjs`는 제외한다(그 규약은 07이 채운다). `bun run test`가 기존 스위트와 함께 이것들을 돈다
- [ ] 어긋남 픽스처가 각각 있다: 레지스트리에만 있음, 표에만 있음, 스크립트 없음, `ci: yes`인데 워크플로 없음, 워크플로가 미등록 게이트를 돌림. 그리고 **전부 일치할 때 통과**하는 케이스
