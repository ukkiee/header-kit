# 넓은 UI 리디자인 — 다크 개발자도구 셸, 테마 스위치, 새 규칙 종류

claude_design 프로젝트("Mod Header 크롬 확장프로그램 디자인")에서 가져온 다크·고밀도 개발자도구 대시보드를 채택한다. 시각 리스타일에 더해 그 디자인이 보여 주는 기능(테마 스위치, User-Agent·Block·Header Removal 규칙, 백업 동기화 스위치)을 실제로 구현한다. 이 ADR은 리디자인이 건드리는 여러 기존 결정의 개정을 한곳에 모은다 (ADR 0014의 shadcn 채택 기록과 같은 형태).

- **맥락**: UI는 shadcn 마이그레이션(ADR 0014)으로 정돈됐지만, 시각 언어는 여전히 밝은 미니멀 톤이었다. 디자인은 이를 다크 개발자도구 대시보드로 바꾸고, 지금 모델에 없는 세 규칙 종류와 테마·동기화 제어를 추가한다. 셸 구조(레일+프로필열+본문)는 이미 두 표면 공유물(ADR 0005)이라 새 레이아웃이 아니라 그 위의 리스타일이다.

- **결정 — 표면·크기 (ADR 0005 재확인)**: 디자인은 "넓은 팝업 1100×700"이라 적혀 있으나 Chrome 팝업은 800×600이 하드 리밋이다. **1100×700은 탭 앱(app.html) 참조 크기**로 삼고, **팝업은 760×580 그대로** 둔다. 두 표면이 같은 다크 셸을 렌더하되 팝업은 프로필 열을 좁게, 탭은 넓은 2열 폼까지 편다. ADR 0005는 개정하지 않는다 — 오히려 그 팝업 크기 결정을 그대로 지킨다.

- **결정 — 테마 스위치 (ADR 0004 개정)**: ADR 0004의 "테마 스위치 없음, 시스템 연동만"을 개정한다. 설정에 **다크/라이트/시스템** 3지 선택을 두고 storage에 영속한다. 디자인의 다크 팔레트(#0a0a0a/#0f0f0f/#141414/#1c1c1c/#262626, 텍스트 #ededed, accent #1d4ed8/#2563eb)가 새 다크 모드가 되고, 라이트는 그에 맞춰 파생한다. global.css의 기존 `[data-theme]` 훅(Storybook·진단용이던 것)을 영속 스위치로 승격한다 — '시스템'일 때만 `prefers-color-scheme`를 따른다.
  - **트레이드오프**: 앱이 테마 선택 상태를 갖게 되어 영속·복원·적용 로직과 라이트 팔레트 설계가 새로 든다. 대신 사용자가 OS와 무관하게 개발 중 다크를 고정할 수 있다.

- **결정 — 새 규칙 종류 세 가지 (유비쿼터스 언어 확장)**: 기존 5종에 더한다.
  - **User-Agent**: `User-Agent` 요청 헤더를 modifyHeaders로 바꾼다. 이름이 고정된 Request Header의 특수 케이스지만, 폼·뱃지·요약이 달라 별도 kind로 둔다.
  - **Block**: declarativeNetRequest `block` 액션으로 요청을 차단한다. 이름·값 없이 URL 스코프와 Condition만 갖는다. **요청 자체를 막으므로 스코프가 넓으면 페이지가 깨질 수 있다** — 릴리스 게이트에서 안전성(과도 차단·차단 범위 표시)을 검토한다.
  - **Header Removal**: 이름이 같은 헤더를 **요청·응답 양쪽에서** 제거한다. 디자인이 req/res를 구분하지 않는 한 종류로 두었으므로, dNR 규칙 하나가 removeHeaders(request)+removeHeaders(response)를 함께 낸다. (요청 헤더만 지우던 기존 `emptyMeans: 'remove'` 경로는 그대로 유효하다 — 이건 "이름만으로 양쪽 제거"라는 별도 어포던스다.)

- **결정 — Geist 폰트 번들 (design-system 무번들 원칙 개정)**: 디자인은 Geist·Geist Mono를 쓴다. 원격 Google Fonts는 확장에서 프라이버시(매 팝업마다 Google 요청)·CSP·오프라인 문제라 배제하고, **woff2를 자가 호스팅으로 번들**한다(@fontsource-variable/geist). design-system.md의 "웹폰트 번들 없음, 시스템 스택" 원칙을 개정한다. shadcn base-nova 프리셋 기본 폰트와도 일치한다.
  - **트레이드오프**: 번들에 폰트 에셋이 더해진다(별도 에셋, JS 게이트 밖). 대신 디자인의 개발자도구 아이덴티티를 그대로 얻고 네트워크 의존이 없다.

- **결정 — 백업 local↔sync 스위치**: 백업이 항상 storage.sync를 쓰던 것을 **켜고 끌 수 있는 스위치**로 바꾼다. ON이면 storage.sync(기기 간 동기화), OFF이면 storage.local(이 브라우저에만). 사용자 대면 라벨은 디자인대로 '클라우드 동기화'로 두어 의미를 직관적으로 전하되, 도메인·내부 용어는 여전히 Backup(브라우저 저장 채널)이다(CONTEXT의 _Avoid_ 주석 참고).

- **경계**:
  - **디버그/로그 패널은 넣지 않는다.** 디자인의 토글은 onRuleMatchedDebug(declarativeNetRequestFeedback) 기반인데 이 API는 압축 해제(개발자 모드) 설치에서만 발동하고 웹스토어 배포판에서는 무동작이라, 켜도 아무 일이 없는 죽은 토글이 된다. 설정에서 뺀다.
  - **일본어(ja)는 넣지 않는다.** 디자인 언어 선택지는 ko/en/ja지만 JA 번역이 없다. 미번역·미검토 문자열을 넣지 않고 ko/en만 둔다.
  - **새 키보드 커맨드는 추가하지 않는다.** 설정의 단축키 패널은 현재 등록된 커맨드(_execute_action, toggle-pause)를 읽기 전용으로 표시만 한다. 디자인의 Alt+Shift+N 등 특정 키는 예시로 본다.
  - **라이브러리는 늘리지 않는다.** 밀집 제품 대시보드라 기존 shadcn+Base UI+Tailwind+Motion으로 충분하다 — Dice/Coss는 해당 concern(테이블·차트·리치텍스트)이 없고, Magic/Cult/Aceternity 마케팅 카탈로그는 밀집 제품 UI에 부적합하다.
